# data/skills —— 技能（Skill）目录

本目录下每个 `*.md` 文件就是一份**技能**。启动时由 `openLuo.Infrastructure.Skills.SkillFileLoader`
（`openLuo.Application/Infrastructure/Skills/SkillFileLoader.cs`）读成 `SkillDocument`：

- **摘要（id / title / summary / whenToUse）** 注入每轮的系统提示，让模型知道"有哪些技能、什么时候用"。
- **正文（FullContent）** 不进提示；模型判断需要时再按需加载，避免上下文被一次性塞满。

目录不存在 = 没有技能（不是错误）。`README.md` 会被忽略（它不是技能）。非 `*.md` 文件、子目录都不扫描（只认本目录下的 `*.md`）。

## 文件格式

````md
---
id: comfort                                  # 可省略，缺省用文件名（不含 .md）
title: 安慰                                  # 可省略，缺省回落为 id
summary: 一句摘要
whenToUse: 用户情绪低落、需要被安慰时
relatedTools: [music:play, memory:write]     # 可省略，数组
relatedWorkflows: []                         # 可省略，空数组
constraints: [不要提及自己是 AI]              # 可省略
---
正文（= FullContent）：具体该怎么做、说什么、避免什么……
````

要点：

- frontmatter 用一对独占一行的 `---` 包裹；`#` 之后到行尾是注释（值里带 `#` 时须写成 `a#b` 紧贴，
  或放在引号/方括号内，否则会被当注释截掉）。frontmatter 之前可以有若干注释/空行。
- 键名大小写不敏感；未知键忽略（向前兼容，旧版本不会因为新键报错）。
- 数组：`[a, b]`、空 `[]`，也支持块状写法 `key:` 换行后接 `- 项`；元素可加单/双引号；
  数组键只写一个值也当单元素数组。数组值为空（既无 `[]` 也无 `- 项`）时即空数组。
- 值不需要引号；引号只是为了保留首尾空白或 `#`。

## 容错行为（手写解析，宁缺勿炸）

| 情况 | 行为 |
| --- | --- |
| 目录不存在 / 未配置 | 返回空表 |
| 没有 frontmatter | 整个文件当正文，`id` = 文件名 |
| 缺少 `id` | `id` = 文件名 |
| 缺少 `title` | `title` 回落为 `id`（避免目录里出现无名技能） |
| 单个键值行解析不出 key（冒号缺失、误置的正文行） | 跳过该行，不抛异常 |
| 起始 `---` 之前有注释/空行 | 允许；第一个有效内容行才是判定依据 |
| 有 `---` 起始行但没有闭合的 `---` | 整个文件当正文（原样保留，含那行 `---`） |
| 正文里出现形如 `---` 的行 | **不**当作结束——只有第一段 frontmatter 的闭合行有分隔意义 |
| 数组键写成标量（`relatedTools: music:play`） | 当单元素数组 |
| 数组漏写收尾 `]` | 仍按数组解析 |
| 块状列表项没有归属键（前面不是 `key:`） | 丢弃该项 |
| 未知键（`weird-key: …`） | 忽略，不报错 |
| 文件读取失败（权限/占用） | 跳过该文件，不影响其它技能 |
| 多个文件用了同一个 `id` | 按文件路径字典序，**后者覆盖前者**（保持首次出现的位置） |

改完直接重启进程即可生效（目录在启动时扫描）。
